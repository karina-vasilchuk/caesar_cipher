# Шифр Цезаря

**Автор:** Карина Васильчук ([@karina-vasilchuk](https://github.com/karina-vasilchuk))

Консольная программа на Java, которая шифрует и расшифровывает текстовые файлы шифром Цезаря,
а также взламывает шифр без ключа: перебором или статистическим анализом.
Проект модуля 1 JavaRush University.

## Возможности

| Пункт меню | Режим | Что нужно |
|---|---|---|
| 1 | Шифрование | исходный файл, файл для результата, ключ |
| 2 | Расшифровка с ключом | зашифрованный файл, файл для результата, ключ |
| 3 | Взлом перебором | зашифрованный файл, файл для результата |
| 4 | Взлом статистическим анализом | зашифрованный файл, файл-образец, файл для результата |
| 0 или `exit` | Выход | |

## Запуск

Нужна Java 17 или новее.

**В IntelliJ IDEA:** откройте папку проекта как Maven-проект и запустите класс `com.javarush.caesar.MainApp`.

**Из командной строки** (из папки проекта):

```bash
mvn compile
java -cp target/classes com.javarush.caesar.MainApp
```

Без Maven:

```bash
javac -encoding UTF-8 -d out $(find src/main/java -name "*.java")
java -cp out com.javarush.caesar.MainApp
```

Пути к файлам можно вводить абсолютные или относительно папки, из которой запущена программа.
Для проверки в проекте есть пример текста `text/input.txt`.

## Алфавит и правила шифрования

Алфавит - 43 символа: русские строчные буквы `а`–`я` (включая `ё`), знаки `. , « » " ' : ! ?` и пробел.
Ключ - число от 0 до 42: на столько позиций каждый символ сдвигается по кругу алфавита.

- Заглавные буквы при шифровании приводятся к строчным.
- Символы не из алфавита (переводы строк, цифры, латиница) при шифровании пропускаются.
- При расшифровке символ не из алфавита считается ошибкой: такой текст не мог получиться при шифровании.
- Результат нельзя записать в исходный файл - программа это проверяет.
- Файлы читаются и записываются в кодировке UTF-8.

## Пример

```
Выберите действие: 1
Исходный файл: text/input.txt
Файл для результата: text/encrypted.txt
Ключ (от 0 до 42): 17
Готово: зашифрованный текст записан в text/encrypted.txt

Выберите действие: 3
Зашифрованный файл: text/encrypted.txt
Файл для результата: text/decrypted.txt
Готово: ключ 17, результат записан в text/decrypted.txt
```

## Как работает взлом

### Перебор (пункт 3)

Программа расшифровывает текст всеми 43 ключами и оценивает, какой вариант больше похож на русский текст.
В оценку входят:

- частоты букв: в русском тексте часто встречаются `о`, `е`, `а` и редко `ъ`, `ф`, `ё`;
- доли пробелов и знаков препинания;
- пробелы вокруг знаков: после `, . ! ?` идет пробел, а перед ними пробела нет;
- частые короткие слова (`и`, `в`, `не`, `на` ...) и гласные в словах;
- длина слов: слов длиннее 20 букв почти не бывает.

На коротком тексте (меньше 4 слов) оценка может ошибиться, поэтому программа показывает
5 лучших вариантов и просит выбрать правильный:

```
Текст короткий, автоматический подбор может ошибиться. Лучшие варианты:
1. [ключ 2] тулезха
2. [ключ 5] привет!
3. [ключ 36] ыьфнрюи
4. [ключ 7] ножагр'
5. [ключ 35] ьэхосяй
Номер правильного варианта (1-5): 2
Готово: ключ 5, результат записан в hi_decrypted.txt
```

### Статистический анализ (пункт 4)

Нужен **файл-образец** - незашифрованный текст того же автора или похожего стиля
(например, другая глава той же книги). Программа считает, как часто встречается каждый символ
в образце, и выбирает ключ, при котором частоты в расшифровке ближе всего к частотам образца.

Чем больше образец и зашифрованный текст, тем надежнее результат. Для проверки образцом может
служить сам `text/input.txt`.

## Большие файлы

Файлы обрабатываются блоками по 8192 символа: блок читается, преобразуется и сразу записывается,
поэтому размер файла не ограничен объемом памяти. Для взлома ключ подбирается по первым
100 000 символов файла, после чего весь файл расшифровывается блоками.
Результат сначала пишется во временный файл, так что при ошибке не остается недописанного файла.

## Структура проекта

```
src/main/java/com/javarush/caesar/
    MainApp.java                    меню, ввод путей и ключа, запуск режимов
    core/Cipher.java                шифрование и расшифровка сдвигом
    core/BruteForce.java            взлом перебором
    core/StatisticalAnalyzer.java   взлом по частотам образца
    service/FileManager.java        чтение и запись файлов блоками в UTF-8
    service/Validator.java          проверка ключа и путей
    exception/CipherException.java  ошибка с понятным пользователю сообщением
text/input.txt                      пример текста
```
